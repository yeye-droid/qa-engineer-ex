# QA Engineer Exam

Automated testing implementation for the Praxxys QA Engineer Exam.

This project contains Laravel Dusk browser tests and Playwright end-to-end tests covering critical application flows.

## Technologies

- Laravel 10
- PHP 8.2
- MySQL/MariaDB
- Laravel Dusk
- PHPUnit
- Playwright
- TypeScript
- Chromium
- Firefox
- GitHub Actions
